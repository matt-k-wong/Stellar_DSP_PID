# Gear profiles

Each file is a complete TOML configuration selected with `--config`.
`config/default.toml` is the generic safe template. Add generic examples or
gear-specific profiles only when their facts are public or explicitly
approved for publication. Keep private equipment observations elsewhere.

For a reusable discovery and measurement workflow, see
[the equipment discovery and gear profile guide](../../docs/gear_profile_discovery.md).

`skyview-pro-example.toml` is illustrative, not an inventory of a particular
setup. It leaves the measurement source blank, active feedback disarmed, and PE
correction off. The mount device name, worm period, and pulse scale require
confirmation or measurement on the actual equipment. See
[the first setup guide](../../docs/skyview_pro_example_setup.md).
